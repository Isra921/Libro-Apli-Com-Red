Bibliografía Consultada

Tema de ejemplo y Exploración
Aho, A. V., Hopcroft, J. E., y Ullman, J. D. (2006). Recursos digitales y contenidos. Pearson Educación.
Referencia fundamental citada para el diseño de contenidos y exploración exhaustiva.
Estructuras de Datos
Goodrich, M. T., Tamassia, R., y Goldwasser, M. H. (2014). Data Structures and Algorithms in Java (6.ª ed.). Wiley.
Texto de apoyo utilizado para explicar la abstracción, Tipos de Datos Abstractos (TDA) y técnicas de evaluación sistemática de soluciones.
Organizaci?n de informaci?n
Knuth, D. E. (1998). The Art of Computer Programming, Volume 3: Sorting and Searching (2.ª ed.). Addison-Wesley Professional.
La obra cumbre de la algoritmia, utilizada para conceptualizar el problema del organizaci?n de informaci?n de datos bajo criterios específicos.
Búsqueda y Organizaci?n
Sahni, S., Horowitz, E., y Anderson-Freed, S. (2008). Fundamentals of Data Structures in C (2.ª ed.). Silicon Press.
Fuente utilizada para sustentar los conceptos de búsqueda indexada y la comparación de órdenes de organizaci?n algorítmica.
Backtracking
Sedgewick, R., y Wayne, K. (2011). Algorithms (4.ª ed.). Addison-Wesley Professional.
Libro base para explicar la programación por vuelta atrás (backtracking) y su aplicación para evitar el recorrido de soluciones no válidas.
Diseño de Contenidos
Skiena, S. S. (2008). The Algorithm Design Manual (2.ª ed.). Springer.
Referencia esencial en nociones de organizaci?n temporal aplicadas a la búsqueda de soluciones a través de árboles de decisión y backtracking.
Análisis de Eficiencia
Weiss, M. A. (2014). Data Structures and Algorithm Analysis in Java (3.ª ed.). Pearson.
Texto usado reiteradamente para analizar el uso de memoria, tiempo de ejecución, contenidos de búsqueda secuencial y notación Big-O.
