Referencias Bibliográficas y Recursos

Fuentes de consulta seleccionadas para fundamentar teórica y prácticamente los contenidos del curso de Aplicaciones para Comunicaciones en Red: literatura clásica de redes, normativas RFC oficiales, esquemas de arquitectura de red y laboratorios prácticos.

Libro de Texto Unidades 1, 2 y 3

Kurose, J. F., & Ross, K. W. (2021). Computer Networking: A Top-Down Approach (8.ª ed.). Pearson.

Texto guía para la comprensión del modelo de capas con orientación descendente, programación con sockets en la capa de aplicación y mecanismos de transporte TCP/UDP.

Capa de Transporte Sockets API Arquitectura TCP/IP
Ficha técnica
Libro de Texto Unidades 1 y 2

Tanenbaum, A. S., & Wetherall, D. J. (2019). Redes de Computadoras (5.ª ed.). Pearson Educación.

Referencia fundamental para el análisis de retardos de transmisión, enrutamiento, conmutación de paquetes y comparativa arquitectónica entre el modelo de referencia OSI y la suite de Internet.

Topologías Enrutamiento Modelo OSI
Ficha técnica
Guía Avanzada Unidad 2: Programación

Stevens, W. R., Fenner, B., & Rudoff, A. M. (2018). UNIX Network Programming: The Sockets Networking API (Vol. 1, 3.ª ed.). Addison-Wesley Professional.

Tratado de referencia para la implementación de servidores concurrentes, multiplexación de E/S con select/epoll y gestión de sockets de bajo nivel.

Sockets POSIX Servidores Concurrentes I/O Multiplexing
Ficha técnica
Consulta Unidad 1

Stallings, W. (2020). Data and Computer Communications (10.ª ed.). Pearson.

Base teórica para medios guiados/no guiados, técnicas de codificación de señales, detección de errores (CRC) y control de flujo en el enlace.

Codificación Control de Flujo Medios Físicos
Ficha técnica
RFC Oficial Unidad 2

Eddy, W. (2022). RFC 9293: Transmission Control Protocol (TCP) Specification. Internet Engineering Task Force (IETF).

Especificación oficial consolidada del protocolo TCP. Describe el formato del encabezado, el intercambio de 3 vías (SYN, SYN-ACK, ACK), estados del autómata finito y retransmisión adaptativa.

RFC 9293 Handshake 3-Vías IETF Standard
Ver RFC
RFC Oficial Unidad 3: Aplicaciones

Fielding, R., Nottingham, M., & Reschke, J. (2022). RFC 9110: HTTP Semantics. Internet Engineering Task Force (IETF).

Estándar fundamental para el desarrollo de servicios web y APIs REST. Detalla métodos idempotentes (GET, PUT, DELETE), códigos de estado y cabeceras de control de caché.

RFC 9110 HTTP / REST Métodos y Códigos
Ver RFC
