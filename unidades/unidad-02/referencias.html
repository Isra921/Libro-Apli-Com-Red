Stevens, W. R., Fenner, B., & Rudoff, A. M. (2018). UNIX Network Programming: The Sockets Networking API (Vol. 1, 3.ª ed.). Addison-Wesley Professional.

Guía práctica para el desarrollo de aplicaciones en red basadas en Java SE: ServerSocket, SocketChannel no bloqueante (NIO) y serialización distribuida de objetos.

Bibliografía Oficial Unidad 2

Downey, A. B. (2016). The Little Book of Semaphores: The Ins and Outs of Concurrency Control and Common Pitfalls (2nd ed.). Green Tea Press.

Texto de referencia oficial para dominar la sincronización de hilos, semáforos, monitores, solución al problema de productores-consumidores y prevención de interbloqueos (deadlocks) en servidores multihilo.

RFC Oficial Tema 2.1

Postel, J. (1980). RFC 768: User Datagram Protocol (UDP). Internet Engineering Task Force (IETF).

Especificación oficial del protocolo UDP. Define la transmisión de datagramas sin conexión, orientación a paquetes y cálculo del checksum de transporte.

RFC 768 Datagramas UDP Checksum

Deering, S. (1989). RFC 1112: Host Extensions for IP Multicasting. Internet Engineering Task Force (IETF).

Estándar fundamental para multidifusión IP e integración con IGMP. Describe el direccionamiento clase D (224.0.0.0 a 239.255.255.255) y el unirse/abandonar grupos multicast en sockets de red.
