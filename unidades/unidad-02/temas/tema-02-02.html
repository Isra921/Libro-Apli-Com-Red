Unidad II · Tema 2.2

Multihilos

La programación multihilo en servidores de red permite desacoplar la escucha de nuevas conexiones respecto a la atención y transferencia de datos de los clientes ya conectados, alcanzando una alta concurrencia.

2.2.1Modelos de atención a clientes en red

Existen diversas alternativas para estructurar servidores que atienden múltiples conexiones simultáneas:

  • Servidor iterativo (Monohilo): Procesa una sola conexión a la vez. Mientras atiende a un cliente, cualquier otro intento de conexión queda en cola o es rechazado. Resulta inaceptable para aplicaciones en producción.
  • Servidor con hilo por conexión (Thread-per-connection): Cada vez que el socket principal ejecuta accept(), lanza un nuevo hilo hijo dedicado a procesar esa sesión. Ofrece una implementación intuitiva pero escala deficientemente ante miles de clientes.
  • Servidor con arquitectura Producer-Consumer y Workers: Un hilo productor acepta las conexiones y las deposita en una cola bloqueante compartida; un pool preasignado de hilos consumidores (trabajadores) extrae las tareas y atiende las peticiones sin incurrir en costos de instanciación continua.

2.2.2Ciclo de vida del hilo de atención

Un hilo de atención cliente ejecuta de forma autónoma su ciclo de lectura y respuesta: 

public class ManejadorCliente implements Runnable {
    private final Socket socket;

    public ManejadorCliente(Socket socket) {
        this.socket = socket;
    }

    @Override
    public void run() {
        try (BufferedReader in = new BufferedReader(new InputStreamReader(socket.getInputStream()));
             PrintWriter out = new PrintWriter(socket.getOutputStream(), true)) {
            String linea;
            while ((linea = in.readLine()) != null) {
                out.println("ECO: " + linea);
            }
        } catch (IOException e) {
            System.err.println("Conexión finalizada: " + e.getMessage());
        }
    }
}
